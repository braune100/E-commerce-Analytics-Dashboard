# E-commerce Analytics Dashboard

This project is an interactive dashboard built using SQL, Python, Pandas, and Streamlit to analyze e-commerce transaction data.

## Features
- Total revenue, orders, and average order value (AOV)
- Sales trends over time
- Top-selling products
- Top customers by revenue
- Country-level sales analysis
- Interactive filters (date and country)

## Tech Stack
- SQL (SQLite)
- Python
- Pandas
- Streamlit

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
